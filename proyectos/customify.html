El problema

Los pequeños y medianos fabricantes (muebles, calzado, merchandising, artesanía) pierden ventas online porque solo pueden mostrar fotos estáticas de sus productos. Sus clientes necesitan ver cómo quedaría el producto final con sus elecciones de color, material o tamaño antes de comprar, pero las soluciones actuales cuestan miles de euros o requieren equipos de desarrollo dedicados.

La solución

Customify es una plataforma SaaS ligera que permite a cualquier fabricante subir un modelo 3D de su producto, definir qué partes son personalizables (color, textura, material) y obtener un enlace público que puede incrustar en su web o compartir con sus clientes. El cliente final ve el producto en 3D dentro del navegador, lo personaliza en tiempo real y ve el precio actualizado al instante.

Tecnologías

Java 17 Spring Boot 3 Spring Security JWT MySQL JPA/Hibernate Flyway Three.js Thymeleaf Bootstrap 5 Docker GitHub Actions JUnit 5

Arquitectura

El proyecto sigue una arquitectura monorepo con dos módulos principales:

  • Backend: API REST con Spring Boot 3, seguridad JWT, persistencia con JPA/Hibernate y migraciones Flyway sobre MySQL 8. Contenerizado con Docker.
  • Frontend Visor 3D: HTML5 + Three.js vanilla (sin frameworks). Carga modelos GLTF/GLB y permite cambiar materiales en tiempo real. Desplegado en GitHub Pages.
  • Panel de Administración: Integrado en el backend con Thymeleaf + Bootstrap 5. Permite a los fabricantes subir modelos, definir opciones personalizables y obtener enlaces públicos.

CI/CD con GitHub Actions: tests automáticos, build y despliegue en Render (backend) y GitHub Pages (visor).

Funcionalidades clave

Visor 3D interactivo

Rotación, zoom y desplazamiento del modelo 3D con Three.js. Cambio de colores y texturas en tiempo real.

Personalización dinámica

El fabricante define zonas personalizables (color, material, texto grabado) y el cliente ve el precio actualizado al instante.

Subida de modelos

Arrastra y suelta archivos GLTF/GLB. El backend valida, almacena y sirve los modelos de forma segura.

Enlace público

Cada producto obtiene una URL única que el fabricante puede incrustar en su web o compartir directamente.

Estado actual
