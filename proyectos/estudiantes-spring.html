Sistema Estudiantes Spring Completado

CRUD completo con Spring Boot, validaciones y arquitectura en capas

El problema

Necesitaba un proyecto sólido que demostrara el dominio de Spring Boot en un entorno profesional, más allá de los típicos tutoriales.

La solución

Construí un gestor completo de estudiantes con operaciones CRUD, paginación, validación de formularios con anotaciones de Jakarta, y una interfaz responsive con Thymeleaf y Bootstrap. Todo estructurado en capas (Controller, Service, Repository).

Tecnologías

Spring Boot Thymeleaf JPA/Hibernate MySQL Bootstrap

Capturas

Arquitectura y decisiones

Utilicé Spring Data JPA para abstraer la capa de persistencia y Thymeleaf como motor de plantillas. Implementé validaciones del lado del servidor y un sistema de mensajes flash para feedback al usuario.
