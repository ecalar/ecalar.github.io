Sistema de gestión de inventario · TFG DAM

Problema

Pequeños negocios necesitan controlar su inventario sin depender de hojas de cálculo desordenadas ni software genérico difícil de adaptar.

Solución

Desarrollé un software de escritorio con Java Swing, altamente personalizable, que permite gestionar productos, categorías, alertas de stock bajo y generación de reportes. La interfaz sigue un diseño minimalista y moderno.

Tecnologías

JavaSwingMySQLMVCDAO

Capturas

Arquitectura y decisiones

Usé el patrón MVC con una capa de persistencia DAO. La base de datos se diseñó con MySQL Workbench aplicando normalización 3FN. Implementé validaciones en tiempo real y un sistema de búsqueda con filtros dinámicos.
