El problema

Pequeños negocios necesitan una herramienta de inventario sin complicaciones, pero las soluciones actuales son demasiado genéricas o requieren formación.

La solución

Diseñé un software de escritorio con Java Swing, altamente personalizable, con una interfaz minimalista y abstracta. Permite gestión de productos, alertas de stock bajo y reportes básicos.

Tecnologías utilizadas

Java Swing MySQL MVC

Capturas

Arquitectura

Utilicé el patrón MVC con una capa de persistencia DAO. La base de datos se diseñó con MySQL Workbench, creando un esquema normalizado hasta 3FN.
