El problema

Las familias, parejas o compañeros de piso suelen perder tiempo y dinero duplicando compras, olvidando qué productos tienen almacenados o dejando que caduquen alimentos en la despensa. La falta de una sincronización en tiempo real y de una visión clara del stock doméstico genera desorganización y compras innecesarias en el supermercado.

La solución

ListaViva es una aplicación móvil desarrollada nativamente para Android que centraliza el control de la despensa y las listas de la compra en un entorno colaborativo. Incorpora un Chef de IA integrado mediante Groq API para sugerir recetas de aprovechamiento basadas en el stock actual, escáner de códigos de barras optimizado con OpenFoodFacts v2 y sincronización en tiempo real.

Tecnologías

Kotlin Jetpack Compose Material 3 Android SDK Groq API (IA Llama / GPT) Firebase Firestore & Auth Hilt (Dependency Injection) Coroutines & Flow CameraX & ML Kit OpenFoodFacts API v2 Git & GitHub

Arquitectura y Decisiones Técnicas

El proyecto sigue los estándares modernos de desarrollo Android recomendados por Google:

  • Arquitectura MVVM & Clean Architecture: Separación estricta de responsabilidades (UI, Domain, Data) asegurando escalabilidad y testing fluido.
  • Resiliencia de Modelos (Fallback): Sistema automático en el cliente de IA que rota entre múltiples modelos (GPT-OSS, Llama, Mixtral) para evitar errores ante caídas de la API.
  • Caché Inteligente y Starter Pack: Precarga optimizada por lotes (Batch) en Firestore y caché local bajo demanda para evitar peticiones redundantes.
  • Seguridad de Credenciales: Ocultación de claves API mediante `local.properties` y `BuildConfig`, protegiendo el código en repositorios públicos.

Funcionalidades clave

Chef de IA Inteligente

Analiza la despensa actual, genera recetas de aprovechamiento y ofrece la opción de refrescar ideas evitando duplicados.

Despensa interactiva

Control visual con estados dinámicos, tarjetas desplegables para consultar códigos de barras y filtrado inteligente sin tildes.

Escáner OpenFoodFacts v2

Lectura rápida integrada con filtros para descartar códigos internos de supermercados de forma automática.

Grupos compartidos

Creación y unión a listas colaborativas mediante códigos seguros sincronizados en tiempo real en la nube.

Estado actual

Aplicación completada, blindada y optimizada, con diseño adaptado a Neo-Brutalismo sobre Material 3, soporte para vibración háptica y preparada para su despliegue y distribución en Google Play Store.
