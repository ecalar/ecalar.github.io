App Recursos Humanos Completado

Gestión de empleados, nóminas y perfiles con JavaFX

El problema

Muchas pymes aún gestionan sus empleados con hojas de cálculo, lo que dificulta la consulta rápida de nóminas, historial y datos personales.

La solución

Una aplicación de escritorio moderna con JavaFX que centraliza altas, bajas, modificaciones y consultas de empleados. Interfaz intuitiva con pestañas, tablas dinámicas y conexión a base de datos MySQL.

Tecnologías

JavaFX MVC MySQL JDBC

Capturas

Arquitectura y decisiones

Implementé el patrón MVC separando la lógica de negocio de la interfaz. Las operaciones CRUD se realizan mediante JDBC con PreparedStatements para evitar inyección SQL.
