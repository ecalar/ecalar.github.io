Archivum Completado

El problema

El secretario de una hermandad gestiona documentos centenarios en papel dispersos por estanterías, archivadores y cajones. Cada consulta obliga a manipular originales que se deterioran con el tiempo, y no existe un sistema para encontrar rápidamente un acta, un título o un expediente concreto. La memoria histórica de la hermandad corre el riesgo de perderse.

La solucion

Archivum es una aplicación de escritorio que permite al secretario digitalizar, catalogar, buscar y preservar todos los documentos históricos y administrativos de la hermandad. Combina una base de datos local con el almacenamiento de los archivos digitales, y ofrece backup completo para garantizar la conservación a largo plazo.

Tecnologias

Java 17 Spring Boot 3.2 JavaFX 21 H2 Database Maven CSS (JavaFX)

Arquitectura de la aplicación

Archivum sigue una arquitectura por capas sobre Spring Boot, con una interfaz de escritorio construida con JavaFX. Toda la aplicación se empaqueta en un único JAR ejecutable, sin necesidad de servidor externo.

  • model: entidades Documento y TipoDocumento.
  • repository: acceso a datos con Spring Data JPA sobre H2.
  • service: lógica de negocio, gestión de archivos y sistema de backup/restauración.
  • ui: ventanas JavaFX con estilos CSS propios.

Persistencia local: base de datos H2 en archivo (data/), archivos digitales en archivos/ y copias de seguridad en backups/. Todo autocontenido en la carpeta del proyecto, sin dependencias externas.

Despliegue: se empaqueta como JAR ejecutable con Maven (mvn clean package) y se lanza con java -jar archivum-1.0.0.jar.

Funcionalidades clave

Subida de documentos

Cada documento se cataloga con metadatos: título, tipo, fecha, descripción y ubicación física.

Búsqueda avanzada

Búsqueda por texto, tipo de documento, rango de fechas o año aproximado.

Detalle y apertura

Vista de detalle con todos los metadatos y apertura del archivo con el programa del sistema.

Edición y reemplazo

Modificación de metadatos y sustitución del archivo sin perder el histórico del documento.

Papelera con restauración

Los documentos eliminados van a papelera. Se pueden restaurar o eliminar definitivamente.

Backup y restauración

Copia de seguridad completa (base de datos + archivos digitales) y restauración desde un backup.

Estado actual

Proyecto completado y funcional. Todas las funcionalidades descritas están implementadas: catalogación con metadatos, búsqueda avanzada, papelera con restauración, y sistema de backup completo. Empaquetado como JAR ejecutable con Maven, listo para usar sin instalación adicional más allá de Java 17.
