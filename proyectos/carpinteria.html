Gestión Carpintería Completado

Digitalización de talleres de carpintería

El problema

Los talleres de carpintería artesanales aún dependen de libretas y hojas de cálculo para controlar el stock de madera, los presupuestos y la cartera de clientes. Esta falta de digitalización genera pérdidas de tiempo y errores.

La solución

Creé una aplicación de escritorio con Java Swing que permite inventariar materiales, crear y almacenar presupuestos, gestionar clientes y generar facturas básicas. Todo desde una interfaz sencilla y funcional.

Tecnologías

Java Swing MySQL

Capturas

Arquitectura y decisiones

Utilicé una arquitectura en dos capas con Swing para la interfaz y JDBC para la conexión a MySQL. La base de datos está normalizada hasta 3FN para evitar redundancias en el inventario.
