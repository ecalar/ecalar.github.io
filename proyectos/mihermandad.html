miHermandad En desarrollo

Plataforma integral de gestión para hermandades religiosas

Problema

Las hermandades manejan grandes volúmenes de datos de hermanos, cultos, inventario y cuotas. Muchas dependen de procesos manuales o herramientas no especializadas.

Solución

Aplicación web con Spring Boot y Thymeleaf que unifica la administración: registro de hermanos, control de pagos, gestión de eventos y patrimonio.

Tecnologías

Spring BootThymeleafMySQLBootstrap

Estado

Desarrollo inicial del módulo de hermanos. Diseño de base de datos completado.
