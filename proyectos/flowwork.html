El problema

Los equipos pequeños y medianos (startups, agencias, consultoras) necesitan gestionar tareas, comunicacion y seguimiento de tiempo, pero se ven obligados a usar 3 herramientas distintas (Trello + Slack + Clockify). Esto genera friccion, perdida de contexto y gastos innecesarios. Las alternativas todo-en-uno como Monday.com son caras y complejas.

La solucion

FlowWork unifica la gestion de proyectos con chat en tiempo real y control horario en una sola plataforma ligera, rapida y de codigo abierto. Esta construida con una arquitectura de microservicios que garantiza escalabilidad, resiliencia y despliegue independiente de cada modulo.

Tecnologias

Java 17 Spring Boot 3 Spring Cloud Eureka RabbitMQ PostgreSQL WebSocket STOMP React Tailwind CSS Docker GitHub Actions Chart.js JWT

Arquitectura de microservicios

FlowWork esta compuesto por 4 servicios independientes, cada uno con su propia base de datos PostgreSQL, comunicados de forma asincrona mediante RabbitMQ:

  • Task Service: CRUD de proyectos, tareas y estados. Tablero Kanban con drag & drop.
  • Chat Service: Mensajeria en tiempo real con WebSocket + STOMP. Salas por tarea.
  • Time Service: Registro de horas, timer inicio/stop y reportes con graficos.
  • API Gateway: Spring Cloud Gateway con autenticacion JWT, rate limiting y enrutamiento via Eureka.

Service Discovery con Eureka Server: cada microservicio se registra al arrancar y el Gateway los descubre automaticamente.

Event Bus con RabbitMQ: eventos como task.completed o time.entry.created se propagan entre servicios sin acoplamiento directo.

Funcionalidades clave

Tablero Kanban

Drag & drop de tareas entre columnas. Vista por proyecto y por responsable.

Chat en tiempo real

WebSocket + STOMP para mensajeria instantanea. Salas vinculadas a cada tarea.

Control horario

Timer con inicio/stop por tarea. Graficos de horas trabajadas por dia y por proyecto.

Eventos asincronos

RabbitMQ propaga eventos entre servicios. Si un servicio falla, los demas siguen funcionando.

Notificaciones toast

Feedback visual en tiempo real para cada accion: crear, completar, eliminar tareas.

Registro y login

Autenticacion JWT con registro de usuarios. Datos filtrados por usuario.
