El problema

Los equipos pequeños y medianos (startups, agencias, consultoras) necesitan gestionar tareas, comunicación y seguimiento de tiempo, pero se ven obligados a usar 3 herramientas distintas (Trello + Slack + Clockify). Esto genera fricción, pérdida de contexto y gastos innecesarios. Las alternativas todo-en-uno como Monday.com son caras y complejas.

La solución

FlowWork unifica la gestión de proyectos con chat en tiempo real y control horario en una sola plataforma ligera, rápida y de código abierto. Está construida con una arquitectura de microservicios que garantiza escalabilidad, resiliencia y despliegue independiente de cada módulo.

Tecnologías

Java 17 Spring Boot 3 Spring Cloud Eureka RabbitMQ PostgreSQL WebSocket STOMP React Tailwind CSS Docker GitHub Actions

Arquitectura de microservicios

FlowWork está compuesto por 4 servicios independientes, cada uno con su propia base de datos PostgreSQL, comunicados de forma asíncrona mediante RabbitMQ:

  • Task Service: CRUD de proyectos, tareas y estados. Tablero Kanban con drag & drop.
  • Chat Service: Mensajería en tiempo real con WebSocket + STOMP. Salas por proyecto.
  • Time Service: Registro de horas, timer inicio/stop y reportes de tiempo.
  • API Gateway: Spring Cloud Gateway con autenticación JWT centralizada, rate limiting y enrutamiento dinámico vía Eureka.

Service Discovery con Eureka Server: cada microservicio se registra al arrancar y el Gateway los descubre automáticamente.

Event Bus con RabbitMQ: eventos como task.completed o time.entry.created se propagan entre servicios sin acoplamiento directo.

Funcionalidades clave

Tablero Kanban

Drag & drop de tareas entre columnas (Backlog, Todo, In Progress, Done). Vista por proyecto y por responsable.

Chat en tiempo real

WebSocket + STOMP para mensajería instantánea. Salas vinculadas a proyectos.

Control horario

Timer con inicio/stop por tarea. Registro automático de duración y reportes por usuario y proyecto.

Eventos asíncronos

RabbitMQ propaga eventos entre servicios. Si un servicio falla, los demás siguen funcionando.
